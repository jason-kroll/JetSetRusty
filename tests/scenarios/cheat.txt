# Cheat mode ("writetyper"): on the floor of First Landing (level 28, miner
# y==104) the code word must be typed contiguously — C parity: any mismatch
# (wrong letter, wrong room, wrong y) resets cheatPos to 0. So "writ" + stray
# 'x' + "etyper" does NOT enable cheat (the x resets, then 'e' != 'w'), and a
# 5+Enter while cheat is off does not teleport. Retyping the full word enables
# cheat mode (Maria/cheat guardians drawn, responder switches to cheat_enabled);
# then hold a level key and tap Enter to teleport (5 -> The Drive, level 4).
# Escape to the title and start again: the cheat persists, so 3+Enter
# teleports straight to Under the MegaTree (level 2) without retyping the code.
