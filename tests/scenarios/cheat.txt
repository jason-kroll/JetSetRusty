# Cheat mode ("writetyper"): on the floor of First Landing (level 28, miner
# y==104) the code word must be typed contiguously — C parity: any mismatch
# resets cheatPos to 0. Three probes each type "writ" (position 4) and then
# cause one mismatch — a stray 'x', the wrong room (set level 33), and being
# off the floor (miner y=88) — followed by "etyper". With the reset, "etyper"
# never completes the word (its first letter 'e' != 'w' at position 0), so
# cheat stays off and 5+Enter does not teleport. Then the full word typed
# contiguously enables cheat mode (Maria/cheat guardians drawn, responder
# returns the level-select handler), and holding a level key + Enter teleports
# (5 -> The Drive, level 4). Escape to the title and start again: the cheat
# persists, so 3+Enter teleports straight to Under the MegaTree (level 2)
# without retyping the code.
frames 1200

400 w 1
405 r 1
410 i 1
415 t 1            # "writ" -> code-word position 4
420 x 1            # stray letter -> resets position to 0

432 set level 28   # back to First Landing
440 set miner 150 88   # off the floor (y != 104) ...
