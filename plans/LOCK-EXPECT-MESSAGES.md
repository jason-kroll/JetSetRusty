# PLAN: name every lock with expect; ratchet unwrap_used

Task: eliminate the 41 bare `.lock().unwrap()` sites (measured at
`7eb0ea4`: video.rs 12, game.rs 12, audio.rs 8, replay.rs 2,
dispatch.rs 2, die.rs 2, rope.rs 1, miner.rs 1, cheat.rs 1) plus the
9 remaining non-lock `.unwrap()`s (levels.rs:5176, replay.rs:103,187,
tests/replay.rs:41,46,100 x2,101, build.rs:15), replacing each with
`.expect(...)` carrying a message that names the mutex or the invariant.
Then deny `clippy::unwrap_used` in Cargo.toml so no future `.unwrap()`
compiles.

Why: `unwrap()` on a poisoned mutex panics with a message that does not
say which lock; `expect("X lock poisoned")` names it. Note the expect does
NOT guard against reentrancy - a non-reentrant deadlock is a silent
freeze, not a panic (AGENTS.md Locking rule) - it only improves the
poison-panic diagnostic. The structural no-reentrancy rule from the
ATOMIC-MIRRORS plan is unchanged.

Message scheme (canonical mutex name regardless of local receiver path):

- `VIDEO_PIXEL.lock().expect("VIDEO_PIXEL lock poisoned")` - 13 sites
  (video.rs x12, rope.rs x1)
- `.expect("GAME_STATE.miner lock poisoned")` - 15 sites:
  `GAME_STATE.miner` x8 at dispatch.rs:136,163; die.rs:50,59;
  src/replay.rs:234,246; cheat.rs:113; miner.rs:649 - and `game.miner`
  x7 in game.rs, five of which are the cfg(test) locks in
  `change_level_above_guard` (the deny is --all-targets, so phase 3
  touches the test module too)
- `AUDIO_STATE.lock().expect("AUDIO_STATE lock poisoned")` - 8 sites (audio.rs)
- `game.score_clock.lock().expect("GAME_STATE.score_clock lock poisoned")` - 3
- `game.timer.lock().expect("GAME_STATE.timer lock poisoned")` - 2
- Remaining unwraps get named-invariant expects, e.g.
  levels.rs:5176 `CString::new(level.title).expect("level title has no interior NUL")`,
  replay.rs:103 `.expect("split always yields a first field")`,
  replay.rs:187 `.expect("dump frame number parses")`,
  tests/replay.rs:41,46,100,101 fs calls
  `.expect("write/read scenario or golden files in tempdir")`,
  build.rs:15 `.expect("date output is UTF-8")`.

Out of scope: `stdout.lock()` in replay.rs:216 is an io lock with no
unwrap - untouched. All `try_from(..).expect(named invariant)` sites are
already the house style and stay.
